POLIMENTO PRE-ENTREGA — JOEDLA COLLECTION

Este pacote aplica somente mudanças de baixo risco.

FAZ
- remove o registro da rota account, se ainda existir;
- remove o botão Conta do cabeçalho, se ainda existir;
- melhora acessibilidade dos botões do cabeçalho/carrinho;
- adiciona metadados Web básicos: pt-BR, título, descrição e theme-color;
- cria auditoria automática para localhost, TODO/FIXME e links /account;
- adiciona:
  npm run audit:release
  npm run check:release

NÃO FAZ AUTOMATICAMENTE
- cria pedido real;
- envia WhatsApp real;
- testa Pix;
- apaga produtos;
- muda dados do Supabase;
- muda lógica do checkout.

Esses pontos continuam em checklist manual para evitar alterações em produção.

COMO USAR

1. Coloque aplicar-pre-entrega.cjs na raiz:
   C:\projetos 2026\joedla-collection1

2. Rode:
   node aplicar-pre-entrega.cjs

3. Depois:
   cmd /c npm run check:release

4. Se o TypeScript estiver sem erros:
   cmd /c npx expo start --web --clear

BACKUP
Arquivos alterados recebem:
.bak-pre-entrega
