IMPORTANTE — SUPABASE (para o e-mail enviar CÓDIGO, e não link):
No painel Supabase:
Authentication > Email Templates > Magic Link

Troque o conteúdo do template para usar {{ .Token }}.
Exemplo:

Assunto:
Seu código de acesso — Joedla Collection

Corpo:
<h2>Seu código de acesso</h2>
<p>Digite o código abaixo na tela da Joedla Collection:</p>
<h1 style="font-size:32px;letter-spacing:6px">{{ .Token }}</h1>
<p>Se você não solicitou este código, ignore este e-mail.</p>

NÃO use {{ .ConfirmationURL }} nesse template, pois isso gera o link mágico.
